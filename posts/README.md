# Posts do Instagram

Cada tema fica numa pasta com `slides.html` (fonte editável), os PNGs (1080×1350) e `legenda.txt`.
Para regerar os PNGs depois de editar o HTML (precisa do Playwright):

```bash
node posts/renderizar.mjs posts/tema-2-como-funciona
```

`fontes/` (Lexend, JetBrains Mono — licença OFL) e `img/` (logo e faixa de parceiros) são compartilhados entre os temas.
